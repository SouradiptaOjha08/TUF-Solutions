# Java Data Structures & Algorithms (DSA) Practice

Welcome to my personal repository dedicated to mastering Data Structures and Algorithms using **Java**. This repository serves as a centralized hub for tracking my learning progress, implementing core DSA concepts from scratch, and solving classic algorithmic challenges.

## 🚀 Project Overview

The goal of this repository is to build a strong foundation in problem-solving and algorithmic thinking. It includes custom implementations of foundational data structures, as well as solutions to problems curated from various platforms like Striver's DSA sheet, LeetCode, and GeeksforGeeks.

## 🛠️ Tech Stack & Requirements

*   **Language:** Java
*   **Requirements:** JDK 21+
*   **IDE:** IntelliJ IDEA (Recommended)
*   **Build System:** Plain Java (IntelliJ modules)

## 📁 Project Structure

The project is organized by topics:

```text
src/
├── arrays/             # Problems related to arrays
├── basic_math/         # Basic mathematics problems
└── pattern_problems/   # Pattern printing problems
```

## 🚀 Setup and Run

### Running in IntelliJ IDEA
1. Open the project folder in IntelliJ IDEA.
2. Ensure the project JDK is set to 21 or higher.
3. Navigate to any `.java` file in `src/`.
4. Click the green "Run" icon next to the `public static void main` method to execute.

### Running in Terminal
To compile and run a specific file (e.g., `src/basic_math/CheckPalindrome.java`):

1. **Compile:**
   ```bash
   javac -d out src/basic_math/CheckPalindrome.java
   ```

2. **Run:**
   ```bash
   java -cp out basic_math.CheckPalindrome
   ```
   *(Ensure you run this from the project root directory)*
